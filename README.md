# ComfyMediaViewer

ComfyMediaViewer V3.0.0 优化源码：保留经典图片／视频浏览界面，接入新版 SQLite 后端，并优化图片加载、连续浏览和最近使用列表。

## 从源码启动

在 Windows 上准备 Python 和 Pillow，然后运行：

```powershell
python -m pip install Pillow
.\start_optimized.bat
```

也可以直接启动并指定媒体目录：

```powershell
python server.py --root "D:\你的图片目录" --no-hotfix --no-update-check
```

默认在浏览器中打开 `http://127.0.0.1:8765/`，端口占用时自动后移。`start_optimized.bat` 禁用旧热更新前端覆盖和自动更新检查，避免与本版源码混用。可用 `CMV_PYTHON` 指定 Python 程序路径。

内容安全模型和推理引擎为可选项；基础浏览使用 Pillow 即可。现有旧 JSON 资料不会自动迁移；新建资料目录初始化为 SQLite。图库、收藏、个人设置及模型文件不随本仓库提供。

## 功能与本次修改

- 图片／视频浏览、分页与连续加载、大图预览、生成参数及原始数据查看。
- 收藏、标签、标记、最近使用，以及工作流库、模型核验和作品关联。
- 路径查询索引、数据库完整性检查复用、缩略图缓存命中路径和目录扫描复用。
- 缩略图请求与解码队列、离屏卡片内容释放、元数据缓存和视频会话管理。
- 详情栏的工作流／模型／作品关联卡片统一滚动，文本框保留自身滚动。
- 左侧旧“工作流”分类改名为“有元数据”，判定规则保持不变。
- 最近使用列表共用状态快照、批量获取版本信息；最新／最早排序按使用时间。

## 验证与边界

2026-10-13 至 2026-10-14 在 Windows、本地 Python 3.14 环境验证过源码运行和隔离后端回归，并完成真实浏览器操作检查。

两万条测试索引中的缓存缩略图请求中位耗时约 138 → 13 ms，100 次路径查询约 2397 → 9 ms。这是特定操作的测试结果，不能作为整个软件或真实两万张图库的提速倍数。

现有预览库的 139 条最近记录：列表读取约 10925 → 45～154 ms，浏览器点击至列表显示约 90 ms。缩略图解码会继续异步完成。

可独立运行回归检查，测试仅生成临时资料和合成媒体：

```powershell
python tests/verify_backend.py
```

复杂筛选、时间轴及部分特殊视图仍使用完整列表。桌面 EXE／Tauri 的同源码构建、真实大图库吞吐和完整迁移恢复故障矩阵尚未完成发行验收。
